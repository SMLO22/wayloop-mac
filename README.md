# WayLoop for older Macs

Downloads of [WayLoop](https://beatsaround.com/wayloop/) for Macs running
**macOS 10.15 Catalina or macOS 11 Big Sur**, which the Mac App Store version
(macOS 12 and later) does not support. On macOS 12 or later, get WayLoop from
the [App Store](https://apps.apple.com/app/wayloop-slow-down-loop/id6827310524)
instead.

This repository holds releases only. Each release is a ZIP containing
`WayLoop.app`, signed with Developer ID and notarized by Apple.

To install: download the ZIP from the latest release, open it, and drag
`WayLoop.app` into Applications.

WayLoop is free, with no ads and no account. Support: https://beatsaround.com/wayloop/support
